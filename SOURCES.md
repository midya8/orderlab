# Sources and prior art

Reviewed November 10, 2026. Sources below establish classical concepts and prior work, not the project's validation counts. Code, developed controls, UI and evidence schema are original; no implementation copied from these projects. No claim of inventing Kemeny aggregation, local optimality, subset dynamic programming or exhaustive enumeration.

1. **Cynthia Dwork, Ravi Kumar, Moni Naor and D. Sivakumar, "Rank Aggregation Revisited".** Primary research paper. Kendall disagreement objective, computational hardness, and adjacent-local versus global Kemeny optimality. The work motivates meta-search; OrderLab does not claim its spam-resistance results or duplicate its local-search algorithm. https://cs.brown.edu/courses/cs253/papers/rank2.pdf
2. **Nadja Betzler, Michael R. Fellows, Jiong Guo, Rolf Niedermeier and Frances A. Rosamond, "Fixed-Parameter Algorithms for Kemeny Scores".** Primary research paper. Definition as sum of Kendall inversions and Theorem 4's candidate-subset recurrence placing one candidate first. This is the direct classical basis of the Python recurrence. Extensions to tied/incomplete votes discussed in the paper are not implemented here. https://fpt.akt.tu-berlin.de/publications/kemeny.pdf
3. **Preference Voting documentation, "Other Methods", Kemeny-Young and Kemeny-Young Rankings sections.** Software documentation. Confirms minimum Kendall-distance definition, returning all minimizing rankings and candidates first in some minimizing ranking. Not used as an execution oracle or runtime package. https://pref-voting.readthedocs.io/en/stable/other_methods.html
4. **"An Analysis of Rank Aggregation Algorithms", arXiv 1402.5259.** Primary research text consulted for rank-aggregation algorithmic context. Its specialized parameterized DP is not represented as this project's simple candidate-subset recurrence. https://ar5iv.labs.arxiv.org/html/1402.5259
5. **Koustav De, Harshil Mittal, Palash Dey and Neeldhara Misra, "Parameterized Aspects of Distinct Kemeny Rank Aggregation", arXiv 2309.03517 (2023).** Primary research prior art for multiplicity of optimal aggregations. Listing all tied optima is not claimed as novel. No advanced enumeration algorithm from this source is implemented. https://arxiv.org/pdf/2309.03517
6. **William H. Press, "C++ Program for Kemeny-Young Preference Aggregation", August 6, 2012.** Author implementation note, prior art for practical heuristic aggregation. Its broad practical-heuristic wording is not a restriction against bounded exact enumeration; OrderLab is deliberately small and exact, with no practical-scale comparison. No code copied. https://numerical.recipes/whp/ky/kemenyyoung.html
7. **Corankco repository.** Existing software supporting exact and heuristic rank aggregation, including broader input forms. Prior art and scope contrast only; no runtime dependency, source copy or performance comparison. https://github.com/pierreandrieu/corankco
8. **SciPy documentation, `scipy.optimize.milp`.** Official numerical API documentation for integer constraints, explicit variable bounds and linear constraints. Used only in the optional HiGHS reference checker, not the exact runtime or certificate. https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html

The pairwise bound, default counterexample arithmetic, append-last equivalence and binary-tournament formulation are explained directly in [METHOD.md](METHOD.md) and tested from supplied profiles. They are standard consequences of the stated objective, not new research results. A possible optimum is not evidence of fair or truthful preferences.
